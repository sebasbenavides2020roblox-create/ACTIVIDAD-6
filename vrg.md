# Actividad: Tipos de datos en bases de datos

## Objetivo
Aprender y comprender los términos clave utilizados en el desarrollo de bases de datos, relacionándolos con ejemplos de situaciones cotidianas.

## 1. Tipos de datos más comunes

| Tipo de dato | Uso |
|---|---|
| INT | Almacena números enteros, por ejemplo una edad o una cantidad. |
| VARCHAR | Almacena texto de longitud variable, por ejemplo un nombre o una dirección. |
| DATE | Almacena fechas, por ejemplo la fecha de nacimiento. |
| DECIMAL | Almacena números decimales con precisión, por ejemplo un precio. |
| BOOLEAN | Almacena valores de verdadero o falso, por ejemplo si una persona está activa. |
| TEXT | Almacena textos largos, por ejemplo una descripción. |

## 2. Ejemplos de uso

- **INT:** edad, número de documento o cantidad de productos.
- **VARCHAR:** nombre, apellido, dirección o correo electrónico.
- **DATE:** fecha de nacimiento, fecha de compra o fecha de una cita.
- **DECIMAL:** precio de un producto, salario o promedio.
- **BOOLEAN:** indicar si una cuenta está activa o si un producto está disponible.
- **TEXT:** observaciones, comentarios o descripciones extensas.

## 3. ¿Qué pasaría si no existieran los sistemas informáticos?

Si no existieran los sistemas informáticos, muchas actividades serían más lentas y difíciles de organizar. Por ejemplo, se tendrían que guardar muchos datos en documentos físicos y realizar cálculos manualmente.

Esto podría provocar:
- Pérdida o deterioro de información.
- Mayor posibilidad de errores humanos.
- Procesamiento más lento de los datos.
- Dificultad para encontrar y organizar información.
- Problemas para compartir información rápidamente.

## 4. Impacto en sectores como la banca, salud y comercio

La falta de sistemas informáticos afectaría bastante estos sectores.

**Banca:** sería más difícil consultar cuentas, registrar transacciones y verificar movimientos.

**Salud:** los hospitales tendrían más dificultades para consultar historias clínicas, citas y resultados de exámenes.

**Comercio:** sería más complicado controlar inventarios, registrar ventas y administrar información de clientes.

### Ejemplos históricos

1. Antes de la digitalización, muchos bancos registraban operaciones en libros y documentos físicos.
2. Las historias clínicas de los pacientes se almacenaban principalmente en archivos de papel.
3. Los comercios llevaban inventarios y registros de ventas manualmente.

## 5. ¿Cómo se realizaban las transacciones antes de los sistemas informáticos?

Las transacciones bancarias se realizaban principalmente de forma presencial. Los empleados registraban las operaciones en documentos y libros físicos y los clientes debían presentar documentos para realizar diferentes trámites.

Las solicitudes médicas también se hacían de manera presencial o mediante documentos físicos. Las citas, historias clínicas y resultados se organizaban en archivos de papel.

## 6. Cuadro comparativo

| Proceso | Antes de los sistemas informáticos | Con sistemas informáticos |
|---|---|---|
| Transacciones bancarias | Se registraban manualmente en documentos físicos. | Se registran y consultan mediante sistemas digitales. |
| Citas médicas | Se solicitaban presencialmente o por teléfono y se anotaban manualmente. | Se pueden gestionar mediante sistemas de citas. |
| Historias clínicas | Se guardaban en archivos físicos. | Se almacenan y consultan digitalmente. |
| Inventarios | Se contaban y registraban manualmente. | Se pueden controlar mediante programas y bases de datos. |
