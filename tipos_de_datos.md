# Tipos de datos en bases de datos

## INT
Guarda números enteros. Ejemplos: edad, cantidad de productos o número de documento.

## VARCHAR
Guarda cadenas de texto de longitud variable. Ejemplos: nombre, dirección o correo.

## DATE
Guarda fechas. Ejemplos: fecha de nacimiento, fecha de compra o fecha de una cita.

## DECIMAL
Guarda números decimales con precisión. Ejemplos: precios, salarios o promedios.

## BOOLEAN
Guarda valores lógicos: verdadero o falso. Ejemplo: indicar si un producto está disponible.

## TEXT
Guarda textos largos. Ejemplos: descripciones, observaciones o comentarios.
